    Error Code Diagnostics in Conway, AR

    Codes like Rinnai LC, Navien E003 or Noritz 90 tell us a lot about what is going wrong. We read the code history, test flame rods, flow sensors and igniters and check gas pressure at the inlet.     Isolation Valve Kit Installation in Conway, AR

    Some tankless heaters were installed without service valves, which makes proper flushing impossible. We install a set of isolation valves with purge ports on the hot and cold lines so future maintenance takes minutes. The kit also lets you shut off water to the heater without closing the main.     Inlet Filter and Air Intake Cleaning in Conway

    Every tankless unit has an inlet water screen that catches grit and scale flakes. Those screens can clog with sand and debris, especially after municipal line work. We pull and clean the screen and inspect the air intake filter, which can load up with dust and dryer lint. Clean filters keep the flow sensor reading correctly and the burner breathing properly.
